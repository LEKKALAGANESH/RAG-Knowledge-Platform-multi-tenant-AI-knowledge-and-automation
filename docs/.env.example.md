# `.env.example` template

Save the block below as `.env` in the repo root (never commit it) and replace every `change-me` value. Variable reference: [ENVIRONMENT_VARIABLES.md](ENVIRONMENT_VARIABLES.md).

Generate secrets:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"      # JWT_SECRET, API_KEY_PEPPER, passwords
uv run --with cryptography python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"  # FERNET_KEYS
```

Notes:

- An empty (or blank) line such as `API_KEY_PEPPER=` or `GOOGLE_OAUTH_CLIENT_SECRET=` counts as unset for
  every optional backend setting: the pepper falls back to the `JWT_SECRET`-derived one, and an OAuth
  connector shows as not configured.
- `FERNET_KEYS` must be a valid Fernet key, or every backend process fails at startup.
